# MBIA2602-Fase2-Ontiveros
Nombre del proyecto: Chatbot para servicio a cliente de empresa de alimentos
Elaboracion de un chatbot para dar servicio a cliente con preguntas, incluyendo clasificación visual 
Problema: El equipo de servicio a cliente es muy lento para dar respuestas a pregunas sencillas
Autor: Jorge Ontiveros
Requisitos (Python 3.10+ y NLTK)
Instrucciones: abrir en Colab y cambiar a runtime GPU
Cargar el archivo de intencones: Intenciones_Ontiveros_UTF8.csv
Cargar las imagenes de prueba (en carpetas test, train, val)
Correr el modelo de texto: MBIA2602_Fase2_Ontiveros_Ampliado.ipynb
Correr el modelo de clasificación visual: MBIA2602_Fase2_Ontiveros_Visual.ipynb
Alternativamente, cargar el modelo (guardado en Google Drive): https://drive.google.com/file/d/14kmX3nLrzK8hXN0xEM0v0dqw6GuoqB-N/view?usp=drive_link
Correr el modelo integrado: MBIA2602_Fase2_Ontiveros_Integrado.ipynb
Cargar las imagenes de prueba (Imagenes_demo)
Correr el modelo usando frases demo y las imagenes demo para las intenciones de catalogo
